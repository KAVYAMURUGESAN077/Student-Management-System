
# Student Management System

## Project Overview
The Student Management System is a Java-based application developed to manage student records. It helps users perform basic operations such as adding, viewing, updating, and deleting student information.

## Technologies Used
- Java
- JDBC
- MySQL
- Eclipse IDE

## Features
- Add new student records
- View student details
- Update student information
- Delete student records
- Search student records by ID
- Create database tables using Java

## Project Structure
- `ConnectionClass.java` – Handles database connectivity
- `Main.java` – Main entry point of the application
- `Methods.java` – Defines student management operations
- `MethodsImplementation.java` – Implements the operations
- `Student.java` – Stores student information
- `TableSetup.java` – Sets up the database table

## How to Run
1. Install Java and Eclipse IDE.
2. Install MySQL Server and MySQL Workbench.
3. Download or clone this repository.
4. Import the project into Eclipse.
5. Configure your MySQL database connection.
6. Add the MySQL JDBC driver to the project.
7. Run `Main.java`.

## Database Configuration
Update the database URL, username, and password in the connection class according to your local MySQL configuration.
